# IntegradorProyecto
El proyecto surge por la incertidumbre de los estudiantes al elegir docentes sin información confiable. Esto genera malas decisiones, retiros y pérdidas económicas. Además, los buenos profesores no pueden destacar. La solución es una plataforma que centralice y valide información, mejorando decisiones y visibilidad docente.
